# Семейные квесты — как запустить (бесплатно)

Приложение работает на бесплатном тарифе Firebase (Spark) от Google: вход через Google, база данных, хостинг, push-уведомления. Напоминания по времени и ИИ-проверку фото выполняет бесплатный Google Apps Script.

Посмотреть без установки: откройте `public/index.html` через любой локальный сервер с параметром `?demo`.

## 1. Проект Firebase (5 минут, в браузере)
1. Откройте https://console.firebase.google.com → **Создать проект** → имя, например `semeynye-kvesty`. Google Analytics можно выключить.
2. **Build → Authentication → Начать → Google → Включить**, укажите e-mail поддержки → Сохранить.
3. **Build → Firestore Database → Создать базу** → регион `eur3 (Europe)` → режим «production» → Создать.
4. **Настройки проекта (шестерёнка) → Общие → Ваши приложения → `</>` (Web)** → любое имя → Зарегистрировать. Копировать конфигурацию не нужно: приложение возьмёт её с хостинга само.

## 2. Публикация (терминал)
Нужен Firebase CLI: `npm i -g firebase-tools` (если есть Node.js) или установщик с https://firebase.google.com/docs/cli.
```
cd semeynye-kvesty
firebase login
firebase use --add            # выберите созданный проект
firebase deploy --only hosting,firestore
```
Адрес приложения будет вида `https://<проект>.web.app`.

## 3. Напоминания, уведомления и ИИ (Apps Script)
1. https://script.google.com → **Новый проект** → назовите «Семейные квесты — сервер».
2. Удалите содержимое `Code.gs`, вставьте файл `apps-script/Code.gs` целиком.
3. **Параметры проекта** → включите «Показывать файл манифеста appsscript.json» → в редакторе откройте `appsscript.json` и замените содержимым `apps-script/appsscript.json`.
4. **Параметры проекта → Свойства скрипта**:
   - `PROJECT_ID` — идентификатор проекта Firebase (например `semeynye-kvesty`);
   - `APP_URL` — адрес приложения (`https://<проект>.web.app`);
   - `GEMINI_KEY` — ключ с https://aistudio.google.com/apikey (бесплатно; без него ИИ-проверка просто выключена);
   - `GEMINI_MODEL` — необязательно, по умолчанию `gemini-3.5-flash-lite`.
5. Выберите функцию **setup** → **Выполнить** → разрешите доступ (Google предупредит, что приложение не проверено: «Дополнительно» → «Перейти»). Скрипт создаст таймер на каждые 5 минут.

## 4. Первое использование
1. Откройте адрес приложения, войдите через Google, создайте семью.
2. **Семья → Пригласить**: код для второго родителя и для каждого ребёнка. Ребёнок открывает ссылку на своём телефоне и входит своим Google-аккаунтом (для детей до 13 лет — аккаунт Family Link; родитель разрешает вход в приложение).
3. На каждом телефоне: **Включить уведомления**. На iPhone сначала «Поделиться → На экран „Домой“» и открыть приложение с иконки (iOS 16.4+).

## Как устроены баллы
- Принятые дела зачисляются каждый вечер (по умолчанию 21:00), тратить их можно после воскресенья в то же время.
- Подарки родителей доступны сразу; ребёнок видит поздравление.
- Двойные баллы и перевод дня в выходной — в «Календаре», день открывается касанием.
- Праздники и официальные переносы Беларуси учитываются автоматически (2025–2027; новые переносы добавляются в `public/core.js`, объект `TRANSFERS`).

## Бесплатные лимиты
Firestore: 50 000 чтений и 20 000 записей в день, 1 ГБ — для нескольких семей хватает с запасом. Фото сжимаются и удаляются по сроку из настроек семьи («Семья» → «Правила баллов»: 1 неделя, 2 недели — по умолчанию, 1 или 3 месяца, или свой срок). Apps Script: 90 минут работы в день; один прогон занимает несколько секунд.
